## Atribución Determinista de Costos (`cost_usd`)

A diferencia de sistemas que reportan costos "desconocidos" o nulos, el módulo `c4.tools.rates` computa el gasto exacto en microdólares por tarea:

```bash
# Cambiar el proveedor target dinámicamente en CLI
c4 run --target llama-3.3-70b-versatile --dataset refunds_v2.json

# Dentro del TUI interactivo
/target groq
/cost last
```

Para inferencia local mediante **Ollama**, la plataforma garantiza un costo estrictamente devuelto de `$0.00` USD, permitiendo pruebas masivas desatendidas con presupuesto cero.

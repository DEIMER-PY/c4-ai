# Fixtures sintéticos
schemas.json define contratos; scenario.json representa solo una comparación sintética de dos casos del dataset (no ejecución completa de los seis casos).
api-responses.json añade rechazo por regresión, evidencia incompleta, trabajos pending/failed y listas vacías.
El frontend puede importar estos JSON hasta que exista API.
Los resultados son ilustrativos: no son evidencia real, no hubo llamadas al gateway y cost_usd null significa desconocido.
Los prefijos son IDs de ejemplo. No interpretar tokens/latencia como medición real.

## Configurar y probar sin repetir trabajo

Desde tu propio clon, actualizar develop sin sobrescribir cambios locales. Revisar el PR de esta entrega antes de depender de archivos todavía en feature. No copiar rutas absolutas ni artifacts privados del equipo de Deimer a tu configuración.

```powershell
uv sync --locked
uv run --locked c4 --help
uv run --locked c4 --target-provider groq doctor
uv run --locked c4 --target-provider groq tui
```

`doctor` sin `--probe` no genera llamadas. En la TUI: `/help`, `/runs`, `/use last`, `/report last`, `/status`. Chat normal y `/demo` consumen proveedor; `/doctor --probe` también. Guardar `.env` local con C4_GROK_API_KEY, C4_GROK_BASE_URL, C4_GROK_MODEL y configuración Groq según la guía; nunca incluir valores en screenshots, navegador, fixtures o PR. La disponibilidad de modelos se valida con el proveedor; no basta copiar el nombre de una referencia creativa.

Para una prueba nueva completa, ejecutar una sola vez `/demo`, registrar el ID y comprobar `/report ID` y `/compare ID`. Un rechazo con regresión es un resultado válido. Una ejecución completa suele usar 14 llamadas; no repetir para grabar cada toma. Para interfaz sin consumo usar fixtures etiquetados o checkpoints propios existentes.

En otra terminal, desde la raíz:

```powershell
uv run --locked c4-api --port 8000
```

Desde `apps/dashboard`:

```powershell
pnpm install --frozen-lockfile
$env:C4_DATA_MODE='api'
$env:C4_API_URL='http://127.0.0.1:8000'
pnpm dev --hostname 127.0.0.1 --port 3001
```

Abrir http://127.0.0.1:3001. El almacén de un clon nuevo puede estar vacío: no es un error. `C4_DATA_MODE=demo` activa fixtures explícitos; no hay fallback silencioso a datos demo si falla API. Revisar /delivery y personalización local, costo desconocido, estados vacíos/errores, teclado, contraste y móvil. No exponer la API local a internet; hoy no tiene autenticación de producción.

```powershell
# Raíz
uv run --locked python -m unittest discover -s tests/unit -p 'test_*.py' -v
uv run --locked python scripts/verify_docs.py
# apps/dashboard
pnpm test
pnpm typecheck
pnpm lint
pnpm build
```

Hermes requiere instalación/configuración propia por humano: [guía MCP](../integraciones/HERMES.md). El bot/token y allowlist de Deimer no se comparten en Git. WhatsApp solo se marcará verificado tras entrada→Hermes→get_report/get_evaluation→respuesta entregada con webhook firmado y remitente limitado.

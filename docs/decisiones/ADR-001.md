# ADR-001 — Core propio, contratos primero y desarrollo local
Fecha: 2026-10-11. Estado: aceptada en el plan por Deimer; revisión de Santiago pendiente.
## Decisión
Python/FastAPI con orquestador propio y Next.js para dashboard. PostgreSQL, Redis/RQ, CLI compartiendo servicios y gateway configurable.
GitHub como fuente común; docs Markdown visibles en Obsidian; Slack como coordinación.
## Razón
Permite frontend/backend paralelos y evidencia explícita del loop sin dependencia de harness externo.
## Consecuencias
Debemos implementar límites, recuperación, trazabilidad y evaluación; no basta diagnóstico LLM.
No construir framework generalista. Seis módulos especializados pueden compartir proceso.
## Alternativas
Framework externo y hosting gestionado: diferidos. Reevaluar con ADR si el core resulta insuficiente.
## Revisión
Cambios de stack, contrato, seguridad o aplicación a producción requieren acuerdo de ambos.

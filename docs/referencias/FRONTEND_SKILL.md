# Skill: Modern Frontend Design Stacks & Web Resources

This reference provides a breakdown of modern tools, frameworks, UI component libraries, animation engines, design inspiration resources, and icon sets tailored for frontend development.

---

## 1. Core Stacks by Use Case

### A. The Standard Production Stack (React Ecosystem)
* **Framework:** Next.js (React) / Vite + React
* **Styling:** Tailwind CSS
* **Primitives / Unstyled UI:** Radix UI / Headless UI
* **Components:** shadcn/ui
* **Animations:** Framer Motion (Motion)
* **Icons:** Lucide Icons

### B. High-Performance & Content-First Stack
* **Framework:** Astro
* **Styling:** Tailwind CSS / CSS Modules
* **Interactivity:** React / Vue / Svelte (Islands Architecture)
* **Smooth Scroll:** Lenis Scroll
* **Icons:** Tabler Icons

### C. Developer Experience & Reactivity Stack
* **Framework:** Nuxt.js (Vue 3) / SvelteKit
* **Styling:** Tailwind CSS / UnoCSS
* **Component Suites:** Nuxt UI / Skeleton UI / Shadcn-Svelte
* **Animations:** AutoAnimate / GSAP

---

## 2. Animated UI Libraries & Visual Effects

* **Aceternity UI:** Advanced visual effects, 3D landing elements, glassmorphism navs, glowing cards.
* **Magic UI:** Micro-interactions, animated text effects, particle backgrounds, interactive buttons.
* **Framer Motion / Motion:** Declarative animations, layout transitions, drag gestures for React.
* **GSAP (GreenSock):** High-performance scroll-driven animations (ScrollTrigger), complex timelines.
* **Lenis Scroll / Locomotive Scroll:** Smooth scrolling inertia and smooth wheel behavior.
* **Spline:** Interactive 3D design embedding for web.
* **AutoAnimate:** Zero-config single-line animation library for DOM elements.
* **React Bits:** Lightweight animated components and visual utilities.
* **Lottie / DotLottie:** Vector animation rendering platform for JSON-based animations.

---

## 3. UI Frameworks, Blocks & Layout Components (Nav, Main, Footer)

* **Tailwind UI:** Official production-ready components, navbars, footers, application shells.
* **shadcn/ui:** Reusable, accessible component system built on Radix UI and Tailwind CSS.
* **Cruip:** Full SaaS landing page templates, HTML/React responsive designs.
* **Relume Library:** Figma and Tailwind component library for wireframing and building layouts.
* **Preline UI:** Open-source Tailwind CSS components for modern web design.
* **Flowbite:** Interactive components and layout blocks built for Tailwind CSS.
* **Radix UI:** Unstyled, accessible primitive components for design systems.
* **Headless UI:** Unstyled UI components designed to integrate with Tailwind CSS.
* **Skeleton UI:** UI component library for Svelte and Tailwind CSS.
* **Nuxt UI:** Component library for Vue and Nuxt applications.
* **DaisyUI:** Utility-first CSS component library built on top of Tailwind CSS.

## 4. Design Inspiration & Layout Benchmarks

* **Awwwards:** Premier showcase for experimental, WebGL-driven, award-winning sites.
* **Godly Website:** Curated list of modern websites with focus on typography and animations.
* **Land-book:** Curation of landing page design patterns and layouts.
* **Lapa Ninja:** Landing page showcase categorized by design themes and industries.
* **Mobbin:** Real-world web and mobile app user flow screens and UI patterns.
* **Siteinspire:** Clean, typography-focused, elegant web design showcase.
* **PageFlows:** Video recordings of real-world web application user journeys.
* **SaaS Landing Page:** Focused gallery of SaaS product landing page designs.

## 5. Vector Icon Systems

* **Lucide Icons:** Clean, consistent SVG icon set for modern web development.
* **Tabler Icons:** Over 4,000 pixel-perfect vector icons.
* **Phosphor Icons:** Flexible icon family with multiple weights and styles.
* **React Icons:** Unified wrapper for popular SVG icon libraries.
* **Heroicons:** Official hand-crafted SVG icons by the Tailwind CSS team.
* **Simple Icons:** SVG icons for popular brand logos and software tools.

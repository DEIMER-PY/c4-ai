## Aplicación en C4

- Preset **Kit claro**: acento#723ceb y superficies claras adaptadas a C4.
- Preset **Kit oscuro**: acento#723ceb, fondo#010101 y tarjetas#1f1f21 adaptadas a C4.
- Se conservan paleta C4, personalización manual, contraste automático, tarjetas existentes y evidencia de API.
- La personalización se aplica desde **Colores** en la barra superior y se guarda únicamente en el navegador. El laboratorio de datos de `/delivery` permanece explícitamente simulado.

Es una adaptación de identidad visual, **no una copia exacta del CRM ni una importación completa del kit**. No se descargó ni se usó la imagen de portada como interfaz; tampoco se añadieron URLs temporales de Figma al código.

Para reproducir exactamente una pantalla se necesitará el frame correspondiente con sus componentes, recursos y capas. Esto sigue pendiente; no impide usar la portada como referencia de estilo solicitada por Deimer.
